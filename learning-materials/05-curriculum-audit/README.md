# 通用阅读教材审查与内容重定

2026-11-16；基线 Git `0f40f7f`。**审查结论：现有课程的问题是选材范围偏窄、基础功能漏项、词头覆盖与实际教学混在一起，随后用结尾课程和临时旁注补齐清单。继续按考题漏词扩充，解决不了这些问题。**

本轮已经逐课读完21课的词表、解释、例句、练习和反馈；核对874条词形读音项及777组优先词；对照独立教材和跨体裁词频，交付新的内容范围、逐项证据、79项具体增补和可直接采用的修订文本。属于编者审查，没有冒称独立日语教师审校。

**后续实际检验：[第6轮跨体裁测试](../04-evaluation/round-06/README.md)。** 79项增补及全部基础候选分别带来1.79、8.75个百分点的词形匹配提升；测试也暴露三领域交集筛选、完整表达和异写统计的问题。这里的候选未因测试而补词，尚未重编为21课。

## 关键发现

1. **语法并非全都简单，而是基础与扩展失衡。** 旧课已讲使役被动、三种わけ等复杂关系，却没有系统教列举、经验、计划与尝试、目的与能力变化。新的[42个功能组](grammar-scope.tsv)逐项写出教学范围、前提、缺口和来源：18组已有、20组部分覆盖、4组缺失。42组中40组基础、2组扩展；不是42个孤立句型，也不是承诺42组一天一个。Irodori全部348条原始句型出现均有[功能归属](irodori-alignment.tsv)。
2. **“词表齐了”没有保证教学衔接。** 第5课说“弟见旁注”但没有；第17课说寒い见前课但前课未出现；第10课答应后面展开てみる，之后未兑现。第16课以上的表释与后文范围解释矛盾。具体位置和替换写法见修订文本。
3. **后两课被当作新增内容的出口。** 第20课称不是新词表，但40条首次列入；第21课还有48条，固定复现安排已没有后续学习日。课程固定60分钟的算术通过，不等于教学负荷合理。
4. **通用选材需要独立的跨体裁依据。** 从BCCWJ的书籍、杂志、报纸、问答、博客分别取证，再用CEJC自然会话旁证；不读取任何测试段落或答案来选词。没有把每种媒体高频等同全日语高频。

完整候选：[vocabulary-proposal.tsv](vocabulary-proposal.tsv)。旧777组审查：[v3-priority-audit.tsv](v3-priority-audit.tsv)。全部874个表项及首教、复现信息：[v3-table-audit.tsv](v3-table-audit.tsv)。统计来源：[summary.json](summary.json)。

候选需在5种书面语域至少3种进入前3000，再结合教材或旧教学词头确定基础候选。规则、显式异写映射及完整表达保留清单在[policy.json](policy.json)。这是透明的编辑边界，不是已证明最优的词数。跨域阈值2000/3000/4000得到1466/2239/3020个词头，说明必须报告取舍，不能假装词表天然唯一。

新候选中的671项未匹配到旧课正式表项，不等于671个已证实的未教知识：其中可能有正文旁注、义项重合和词元粒度问题。79项是已进一步审定教学用途的优先内容。语料里的古式词头写法只用于检索，不要求学生把此れ、迚も当日常标准写法。

## 依据及其边界

- [GENKI第3版官方介绍](https://genki3.japantimes.co.jp/intro/)和[学习项目表](https://bookclub2.japantimes.co.jp/download/files/genki3/genki-3rd_syllabus_J.pdf)：用于完整初级功能对照，未复制原书课文。其综合教学时数不能直接转换成本项目的阅读课下界。
- [国际交流基金Irodori资料](https://www.irodori.jpf.go.jp/resources.html)：复用仓库已冻结的348条句型、4246条词汇出现记录及语法解释索引，保留原册/课/记录ID。348条不是348个独立规则。
- [BCCWJ「中纳言」公开数据](https://clrd.ninjal.ac.jp/bccwj/bcc-chu.html)：使用v1.1，未误用页面标为旧版的v1.0。PB/PM/PN采用官方合并且去重的语域列；不再把固定长和可变长次数重复相加。五种语域来自同一语料库，不称五家独立验证。
- [CEJC词汇表](https://www2.ninjal.ac.jp/conversation/cejc/cejc-wc.html)：使用ver202209完整200小时版，不是50/100小时监测版。按来源要求注明：Koiso et al. (2022), *Design and Evaluation of the Corpus of Everyday Japanese Conversation*, LREC2022, pp.5587–5594。
- Tae Kim与Kaishi沿用既有来源清单和原件哈希。前者辅助规则核对；后者辅助教学词定位。Anki是卡片载体，某副牌的收词不能单独证明跨体裁常用性。

这些语料不是2026年即时采样；书籍语域也不单独代表现代轻小说。词频单位不是已消歧的教学义项，不能据此推算“理解90%”。完整来源、版本、原件哈希和用途在[sources.json](sources.json)。第三方原表/PDF只存忽略目录，遵守原资料研究教育用途与再分发限制；这里保存自己的审查决定、引用定位及分析结果。

## 在另一台设备重算

先按[工作区入口](../START-HERE.md)完成原有setup。以下脚本只用Python标准库：

```sh
python3 learning-materials/05-curriculum-audit/build.py --fetch
python3 learning-materials/05-curriculum-audit/build.py --check
python3 learning-materials/tools/workspace.py check
python3 learning-materials/tools/workspace.py regression --current
```

`--fetch`从已登记官方地址下载并验证哈希。CEJC压缩包约78MB，脚本用HTTP范围读取只取所需TSV，仍校验ZIP CRC和解压后的SHA-256，不要求另装库。来源取消范围下载或变更内容时明确失败，不接受不同版本。原件位于 `.cache/curriculum-audit/`，不上传仓库。

`build.py --check`核对源文件哈希、旧课未变、选词派生结果、79项全部有独立证据、语法前置关系无环、21课审查齐全及来源ID有效；不会证明解释完全正确或学生已掌握。后续改动旧课会使此审查基线校验失败，应保留本次结果、创建新版本审查，不重写历史。

验证记录见[VALIDATION.md](VALIDATION.md)。原工作区回归是已曝光材料上的历史一致性检查，与本轮内容规格是否有效分开。
