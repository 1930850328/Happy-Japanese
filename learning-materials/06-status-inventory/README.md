# 已有成果与未落实事项盘点

盘点日期：2026-11-17。基于本机实际文件与检查结果，Git HEAD 为 `0f40f7f59b26c13502e223bf5776ac8800ed43e5`，包含此前尚未提交的研究文件。本轮只盘点、增加导航，不改课程、选词、测试规则或历史成绩。

## 结论

**现有成果是“一套完整的 v3 课稿＋可复用资料池＋多轮诊断＋尚未落实的修订方案”，不是已经改好并验证达到90%的新课程。**

1. 21课确实存在，777个优先教学组均有词表和当课日文用法。不能再说只有大纲、没有完整表达，或重新从零收集已有教材。
2. 后来的79项增补、1308项基础候选、42组功能审查及纠错稿，没有覆盖21课。当前29个审查基线文件仍逐字节一致。新增报告不等于新增教学。
3. 约70%来自对**旧课**的编者阅读模拟；58.2%来自**未编课候选范围**的词形检索。两者不是课程改进前后的成绩。
4. 通用阅读内容范围尚未定稿。用户已否定“跨体裁交集阈值就能决定必教内容”的做法；原始词频、教材和逐课审查仍可复用，不能把旧候选自动升级为新标准。
5. 测试侧也有欠账：没有新保留集、完整评分草稿未经独立复核、模拟仍有评分疑点；现有结果不能证明21天后跨材料读懂90%。

**反复返工的流程断点**：把资料收集、范围提案、正文落地和效果验证混在一起汇报；尚未完成前一轮落地，又用旧课进行另一种测试，再启动选材。第二个断点是只查正式词表，漏掉正文已经教过的内容，制造了部分假缺口。本次将这两条链分开对账。

## 未落实事项的全貌

详细完成条件与责任文件在[pending.tsv](pending.tsv)。按下一步决策需要归纳如下：

1. **内容范围尚未闭合。** 现有材料池、频率表、777组审查不需重做收集；还欠通用必教内容的最终取舍、义项/搭配/活用的明确范围，以及“已在正文教过”和“确需新增”的去重。1308、79和42分别是不同单位，不能相加成课程规模。
2. **已确认的课文问题未修。** 逐课清单已覆盖1—21课，不另造第二套清单。明确实例有：第2课辨形示例不充分；第5课弟回链与路径を先用；第7课気分义项；第10课错误推断和未兑现的てみる讲解；第12课不自然提示；第13课把解释强译为因为；第16课以上词表矛盾；第17课寒い错误回链；第19课敬语方向；第20/21课结尾新增负荷。它们在[原纠错稿](../05-curriculum-audit/corrections.md)和[逐课审查](../05-curriculum-audit/lesson-review.tsv)中，尚未落实到正文。
3. **基础功能的“已有／部分／缺失”尚需落实为教学内容。** 旧审查缺失的基础组是列举、经验、反事实后悔/评价等；计划、尝试、目的、构词、数量时间等多为部分覆盖。不能把20个“部分”统称没教，也不能把4个缺失全称基础必教。先完成范围裁定，再安排落课。
4. **时间与教学顺序仍未验证。** 最高一天59新表项，最多156复现项；第20/21天仍新增40/48表项。预算相加60不等于真人学会。中途休息后如何恢复、遗忘影响也没有实测；当前课程允许休息只是设计规则。
5. **测试能诊断，但尚不能支撑全日语90%的结论。** 旧50:50、单轮五类等权、模拟按意思单位汇总是三个不同口径。没有新保留集；32份答案均为草稿；模拟有待复核判分；少量作品、同出版社/平台、开篇偏差、真实书面聊天等缺口仍在。普通书籍与不同用途不能靠一篇旧科普文章替代。
6. **异地继续工作的边界要明确。** 工具和大量资料恢复已经做过；第6轮完整网页/人工转写和部分旧原件仍不能一键恢复。当前新审查及第6轮仍未提交，本轮不推送；其他设备只下载现有HEAD不能得到这些未提交成果。最终需要交付时再按明确授权提交、验证远端。
