# 课程工作区

先读 [START-HERE.md](START-HERE.md)。这是独立研究目录，修改不代表接入网站或发布课程。

- 教材筛选以 `01-materials/vocabulary-scope/selection.json` 为准；教学正文以 `02-course-design/lessons/*.md` 为准；派生索引用现有脚本生成，不能另外手改一套。
- 保持21个学习日、每天不超过60分钟。排课分钟数、文件出现和学生掌握是不同证据，报告中明确区分。
- 修改后先review、运行 `workspace.py check` 和 `workspace.py regression --current`。回归材料已经曝光，不能当新材料成绩。
- 对新课程效果的验证：先冻结，再读未用于该次修改的新系列，保留原文定位和哈希，同输入比较旧新版本并检查整句。用后的样本转回归。不要通过修改历史成绩、减少困难样本或回填答案来提高分数。
- 不上传被 `.gitignore` 排除的第三方原件、全文派生资料、字幕或漫画转写。保留来源、许可、哈希及下载路径；需要原句时从已记录来源读取。
- 第5轮的无句序词形特征仅支持词形回归，不能重建整句理解、画面理解或模拟真人成绩。集合外新词须回到原文评估。
- 修改部署、应用代码、凭据、提交或推送需要相应任务授权；本目录工作不自动扩大到这些范围。
