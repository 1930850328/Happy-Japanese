# 21天日语阅读入门 v4

**2026-11-17：21课正文已完成。** 面向中文母语、日语零基础、以阅读为主的学习者。每天最多60分钟，包含复习、查表、练习、核对和休息。以读懂基础句子和简单短文为目标，不承诺21天读懂90%的漫画、小说或其他生肉。

[开始第1天](lessons/01.md) · [逐课来源与取舍](SEQUENCE.md) · [自审记录](REVIEW.md) · [本轮验证](../04-evaluation/round-07/README.md)

## 怎样学

每天依次做旧词回想、看本课词表、读讲解与对比句、遮住答案读连续文本、核对后重读。无需写汉字、练口语或另开Anki任务；读音用于字形和词义对应。首次三天有完整假名表，此后继续混合回认，不把见过一遍当熟练。复习是有意重复，新授和复现分开计数。

课内时间到60分钟就停止，未完成如实记下；不能记作已掌握，也不增加隐形课外作业。课文示例全部为教学编写，答案用于反馈，不能算独立学习成绩。

## 这版实际装入多少

- 正式词表271个词形＋读音条目；其中明确同词异写合并7组，时刻构式「半」归语法，因此核心词汇/表达263组。271不是271个独立词根，也不是已掌握数。
- 每天首次词表条目最多22个，固定复习峰值58个；旧版分别59和156。最后两天零新增词表，集中读文与自查。
- 语法以本页每天的主题和正文为准；1355组候选及66单元旧方案没有整体编入，不能继续按旧方案数量宣传本课。
- 数字/日期查询、例外形式和少量带释义的辨形示例也耗时，不因未列词表就忽略。第16天查询表不要求一次全部背熟。

第4—19天安排：复习与假名回认12分钟、词义与短句18分钟、句子关系12分钟、连续阅读与核对13分钟、休息5分钟。第20—21天：复习10分钟、独立阅读25分钟、核对重读20分钟、休息5分钟。前三天依各课字形任务单列预算。**这是排课，不是已测得真人都能完成。**

## 学完能够期待什么

合理的教学目标是：认识基本字形，能在简单文本中找出动作参与者、肯否、时间、修饰和因果条件，开始借助查词阅读较短真实文本。未系统覆盖的推量、复杂敬语、列举等已在SEQUENCE列明；广泛生肉仍会有大量陌生词。结课12题只检验课程内四段短文，不换算通用阅读百分比。
