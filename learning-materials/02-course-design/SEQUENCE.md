# v4：21天阅读入门的内容与依据

以中文零基础、只练阅读、每天总计60分钟为边界。前版资料池保留，1355组方案不整体入课。课程正文是唯一学生教材，本页只记录目的、来源与取舍。

复用Tae Kim中文教材、Irodori词汇和348条句型、GENKI官方学习项目表。对应的Irodori记录ID和GENKI项目见[42组来源映射](../05-curriculum-audit/grammar-scope.tsv)；该表旧课状态属于v3，不代表v4全部覆盖。学生不必在60分钟之外阅读原教材。

## 每天教什么

<a id="day-01"></a>
**第1天：[平假名](lessons/01.md)**。46基本字、辨形、词内识别。依据G01、[hiragana](../01-materials/reader/tae-kim-zh/hiragana.html)。不要求首日自动识别或默写全部。

<a id="day-02"></a>
**第2天：[片假名](lessons/02.md)**。两套对应、シツソン、长横、外来词。依据G01、[katakana](../01-materials/reader/tae-kim-zh/katakana.html)。之后混合复现。

<a id="day-03"></a>
**第3天：[组合与汉字词](lessons/03.md)**。浊半浊音、拗音、促音、长音、整词读法、数字。依据G01—03、[kanji](../01-materials/reader/tae-kim-zh/kanji.html)、[numbers](../01-materials/reader/tae-kim-zh/numbers.html)。不背孤立汉字全部读音。

<a id="day-04"></a>
**第4天：[判断句](lessons/04.md)**。は/も/の、肯否、です/だ、か、指示与疑问。依据G04—06、[stateofbeing](../01-materials/reader/tae-kim-zh/stateofbeing.html)、[particlesintro](../01-materials/reader/tae-kim-zh/particlesintro.html)。暂缓否定疑问应答。

<a id="day-05"></a>
**第5天：[动作参与者](lessons/05.md)**。ます/ません、を对象、で地点、に/へ目标、同行と。依据G04—07、[verbparticles](../01-materials/reader/tae-kim-zh/verbparticles.html)、[polite](../01-materials/reader/tae-kim-zh/polite.html)。先给具体对应，再归纳活用。

<a id="day-06"></a>
**第6天：[时间与过去](lessons/06.md)**。ました/ませんでした、でした、时间に、もう/まだ。依据G03—04、[polite](../01-materials/reader/tae-kim-zh/polite.html)。まだ食べていません先作为整体引入，第8—9天拆开。

<a id="day-07"></a>
**第7天：[描述与比较](lessons/07.md)**。い/な类、肯否过去、修饰、くて/で、より/ほう。依据G08、[adjectives](../01-materials/reader/tae-kim-zh/adjectives.html)、[comparison](../01-materials/reader/tae-kim-zh/comparison.html)。不穷举近义形容词。

<a id="day-08"></a>
**第8天：[活用回认](lessons/08.md)**。五段/一段/不规则，ない/た/て，连接动作，离开场所を。依据G07、G09、[verbs](../01-materials/reader/tae-kim-zh/verbs.html)、[negativeverbs](../01-materials/reader/tae-kim-zh/negativeverbs.html)、[past_tense](../01-materials/reader/tae-kim-zh/past_tense.html)。泳ぐ仅作查询示例，不在闭卷题中突然使用。

<a id="day-09"></a>
**第9天：[存在与状态](lessons/09.md)**。ある/いる、位置、ている、知っている/知りません。依据G05、G09、[teform](../01-materials/reader/tae-kim-zh/teform.html)。不用“正在”覆盖所有状态。

<a id="day-10"></a>
**第10天：[原因与转折](lessons/10.md)**。から/ので、けど/が/のに、だから/でも、顺序连接。依据G15、[compound](../01-materials/reader/tae-kim-zh/compound.html)。暂缓からこそ、おかげ/せい等扩展。

<a id="day-11"></a>
**第11天：[修饰与名词化](lessons/11.md)**。中心名词、内外主语、の/こと。依据G11、[clause](../01-materials/reader/tae-kim-zh/clause.html)、[genericnouns](../01-materials/reader/tae-kim-zh/genericnouns.html)。先练谁做什么，暂缓多层嵌套。

<a id="day-12"></a>
**第12天：[请求与规则](lessons/12.md)**。ください、ないで、てもいい、てはいけない、必须与不必。依据G18、[requests](../01-materials/reader/tae-kim-zh/requests.html)、[must](../01-materials/reader/tae-kim-zh/must.html)。同一动作做肯否关系对比。

<a id="day-13"></a>
**第13天：[愿望和能力](lessons/13.md)**。たい/欲しい、欲しがる识别、可能形、全懂与懂一点。依据G19、G26、[desire](../01-materials/reader/tae-kim-zh/desire.html)、[potential](../01-materials/reader/tae-kim-zh/potential.html)。不要求主动产出所有第三者表达。

<a id="day-14"></a>
**第14天：[时序与条件](lessons/14.md)**。前/後/てから/時/間、たら/と/なら/ば基础识别、开关与开始的自动他动。依据G10、G14、G16、[conditionals](../01-materials/reader/tae-kim-zh/conditionals.html)、[timeactions](../01-materials/reader/tae-kim-zh/timeactions.html)。暂缓条件互换细节、うちに/ところ/まま。

<a id="day-15"></a>
**第15天：[引述与授受](lessons/15.md)**。と言う/と思う、あげる/くれる/もらう、て授受、借入借出。依据G24、G28、[actionclause](../01-materials/reader/tae-kim-zh/actionclause.html)、[favors](../01-materials/reader/tae-kim-zh/favors.html)。不增加敬语变体。

<a id="day-16"></a>
**第16天：[数量与费用](lessons/16.md)**。时刻/时长/价格、星期、日期查询、以上以下未满、まで/までに。依据G03、[numbers](../01-materials/reader/tae-kim-zh/numbers.html)。星期列入正式词表；日期和音变查询不要求当日全背熟，查表也计入60分钟。

<a id="day-17"></a>
**第17天：[经历与变化](lessons/17.md)**。たことがある、ている结果、てある/ておく/てしまう、なる/ようになる。依据G09、G13、G23、[unintended](../01-materials/reader/tae-kim-zh/unintended.html)、[surunaru](../01-materials/reader/tae-kim-zh/surunaru.html)。减少新词，练已知动作的关系。

<a id="day-18"></a>
**第18天：[口语与人物立场](lessons/18.md)**。てる/ちゃう/なきゃ、の/んだ、句尾省略、被动/使役基础辨读。依据G25、G27、G32—34、[causepass](../01-materials/reader/tae-kim-zh/causepass.html)、[slang](../01-materials/reader/tae-kim-zh/slang.html)。暂缓使役被动、角色语及敬语同形，不要求熟练产出。

<a id="day-19"></a>
**第19天：[信息说明](lessons/19.md)**。安全、入口出口、联系、身体不适、变更确认、两种礼貌请求。依据G03、G05、G18及既有Irodori生活词汇。安全/薬等按基本生活需要选入，不按新测验补词。

<a id="day-20"></a>
**第20天：[连续阅读](lessons/20.md)**。三篇原创留言/通知/故事，零新增词表。

<a id="day-21"></a>
**第21天：[结课自查](lessons/21.md)**。四段原创短文、12个信息问题，分别记独立和查后表现；零新增词表。不能冒充陌生真实作品测试。

## 计量与明确暂缓的内容

正式词表含少量汉字/假名重现，词根、词形、语法结构不能相加成“掌握词汇”。查询表、整体引入和规则例子也耗时，不因没列为新词而免费。每课60分钟是排课约束，尚未真人计时。

固定复习取首次词表教学后的第1、3、7个学习日，是编排而非已证明最佳间隔；另有课文复现。最后两天不扩词。第18天内容复习窗口短，不能声称长期掌握。

暂缓复杂敬语、使役被动、文语否定、角色语、复合动词穷举、各类わけ否定、复杂后置表达及大量扩展词。中心／歴史／警察／能力等有用候选也没有全部加入；本期优先基础任务与复习。资料池存在不算已教。

や/たり/し的全部列举形式、疑问词＋も/でも、推量/传闻等也未系统覆盖。遇到这些仍会有缺口，这是本版入门范围，不宣称完整初级课程或90%生肉理解。
