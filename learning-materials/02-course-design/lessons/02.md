# 第 2 天：认出片假名里的词

时间上限：复现 8 分钟；新字 22 分钟；辨形 10 分钟；词内辨认 10 分钟；收束 5 分钟；休息 5 分钟。

先修：第 1 天。依据：[片假名](../../01-materials/reader/tae-kim-zh/katakana.html)。今天换的是字形系统，不是另学 46 套声音。

本课复现包含[第 2 天词形回想](../RECALL.md#day-02)，使用上面的既定时间，不另加背词任务。

## 1. 先复现

不看昨天的词表，辨认`いえ／ほん／ひと／ねこ／くるま`。随后区分`ぬ／め``ね／れ／わ`。

<details><summary>核对</summary>

家、书、人、猫、车。ぬ nu／め me，ね ne／れ re／わ wa。今天复习的是字形到意思的对应，不重讲整张表。

</details>

## 2. 对照两套字形

| 片假名 | 对应平假名 |
| --- | --- |
| ア イ ウ エ オ | あ い う え お |
| カ キ ク ケ コ | か き く け こ |
| サ シ ス セ ソ | さ し す せ そ |
| タ チ ツ テ ト | た ち つ て と |
| ナ ニ ヌ ネ ノ | な に ぬ ね の |
| ハ ヒ フ ヘ ホ | は ひ ふ へ ほ |
| マ ミ ム メ モ | ま み む め も |
| ヤ ユ ヨ | や ゆ よ |
| ラ リ ル レ ロ | ら り る れ ろ |
| ワ ヲ ン | わ を ん |

片假名常写外来词，也能写名字或强调，不代表“这一定是英文”。ヲ与を对应，日常外来词中很少出现，仍要认得。

看`シ／ツ`时观察两短点的位置与长笔方向；看`ソ／ン`也观察短点与长笔的关系。印刷字体会变，不能只记“某一笔倾斜多少度”。用成词的例子反复确认：`スシ`里的シ，`ナツ`里的ツ；它们分别是すし、なつ的片假名写法，本课只作辨形，不作为新词考核。

## 3. 今天的词

| 词形 | 读法 | 本课意思 |
| --- | --- | --- |
| カメラ | かめら | 相机 |
| テスト | てすと | 测验 |
| ホテル | ほてる | 酒店 |
| メモ | めも | 笔记、便条 |
| アニメ | あにめ | 动画 |
| クラス | くらす | 班级 |
| タクシー | たくしー | 出租车 |
| コーヒー | こーひー | 咖啡 |
| メール | めーる | 电子邮件 |
| ノート | のーと | 笔记本 |

长横`ー`把前一个音中的元音延长一拍，不是减号。例如コーヒー可拆为コ・ー・ヒ・ー，共四拍；メール是メ・ー・ル，三拍。平假名中的长音写法明天继续。

`アニメ／カメラ`分别是动画／相机。两者都能出现在影音菜单上，但不是同义词；先看清第一个字再联系意思。

## 4. 先认形，再认义

把左右对应起来，不按表中顺序背：

> シ　ツ　ン　ソ　ク　ケ　ヌ　ス　チ　テ

备选平假名：け、す、し、て、ぬ、ん、ち、つ、そ、く。

<details><summary>核对</summary>

し、つ、ん、そ、く、け、ぬ、す、ち、て。若把ソ读成ン，回到字形表对照；再辨认单独的ソ／ン，不能只猜是某个外来词。

</details>

## 5. 换成生活中的字串

以下是三张独立标签，不是句子：

> ホテル　タクシー
>
> コーヒー　カメラ
>
> クラス　テスト　ノート
>
> メール　メモ　アニメ

哪一行最像教室桌面的便签？哪一个词是一种饮料？哪两个词与住宿、出行有关？

<details><summary>解释</summary>

第三行：班级、测验、笔记本。饮料是コーヒー。住宿与出行是ホテル、タクシー。场景只帮助联系意思，不替代逐词认识。

第四行是邮件、便条、动画；区分“要读的信息”和“影像内容”。邮件和动画也可能包含声音，本课只辨认标签含义。

</details>

最后混读`ほん／ノート``メモ／わたし``カメラ／ねこ`。它们各是不同的词，不要把平片假名混合误认为两个词自动构成句子。
