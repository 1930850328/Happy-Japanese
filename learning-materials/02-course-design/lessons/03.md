## 1. 先复现

遮住中文读`ホテル、メール、メモ、ほん、ひと、わたし`。确认シ≠ツ、ソ≠ン、ね≠れ。

<details><summary>核对</summary>

酒店、邮件、便条、书、人、我。这里复现旧词是为了在加浊点、小字以前稳住基本字形。

</details>

## 2. 把组合规则一次看清

浊点`゛`和半浊点`゜`改变字音。下面两套字对应着读，左边平假名，右边片假名：

| 平假名／片假名 | 读音索引 |
| --- | --- |
| がぎぐげご／ガギグゲゴ | ga gi gu ge go |
| ざじずぜぞ／ザジズゼゾ | za ji zu ze zo |
| だぢづでど／ダヂヅデド | da ji zu de do |
| ばびぶべぼ／バビブベボ | ba bi bu be bo |
| ぱぴぷぺぽ／パピプペポ | pa pi pu pe po |

じ／ぢ、ず／づ在现代标准日语中通常同音，但不能随意换字。先按整个词记写法，不在这里背历史音变。

小ゃゅょ和前面的字组成一拍；大やゆよ另占一拍。全部常用组合如下，不需要重复背每一格十次：

| 平假名 | 片假名 |
| --- | --- |
| きゃ きゅ きょ | キャ キュ キョ |
| しゃ しゅ しょ | シャ シュ ショ |
| ちゃ ちゅ ちょ | チャ チュ チョ |
| にゃ にゅ にょ | ニャ ニュ ニョ |
| ひゃ ひゅ ひょ | ヒャ ヒュ ヒョ |
| みゃ みゅ みょ | ミャ ミュ ミョ |
| りゃ りゅ りょ | リャ リュ リョ |
| ぎゃ ぎゅ ぎょ | ギャ ギュ ギョ |
| じゃ じゅ じょ | ジャ ジュ ジョ |
| びゃ びゅ びょ | ビャ ビュ ビョ |
| ぴゃ ぴゅ ぴょ | ピャ ピュ ピョ |

例如きゃ是 kya，しゃ是 sha，ちゃ是 cha，じゃ是 ja；每行后两格换成 u、o。小っ／ッ是停顿占位的一拍，不读成つ，例如きって是き・っ・て；きて只有两拍，字不同，词也可能不同。

平假名长音常用元音字表示：おかあさん的あ、おにいさん的い；`せんせい`中えい、`がっこう`中おう通常形成长音。**不是所有相邻元音都一概合并**，先按词的读法辨认。片假名主要用ー。

外来组合如ファ／フィ／フェ／フォ、ティ／ディ、チェ、シェ、ジェ、ウィ／ウェ／ウォ，是用小字补足声音。本课认出它们是一组即可；具体词遇到时仍给读法。ヴ常表示 v 音，不必额外训练口音。

以前的词换成汉字：本＝ほん、人＝ひと、私＝わたし、朝＝あさ、家＝いえ。不是新意思。汉字旁标的小假名叫注音；`学校（がっこう）`把整词的读法给你，不要求先学会每个汉字所有读音。

把词义连成几组标签来辨认：`先生／学生`老师／学生，`日本語／勉強`日语／学习，`電車／バス`电车／公交车，`切手／パン`邮票／面包，`スーパー／病院`超市／医院。先遮词义找“学习者”“交通工具”“卖食品的地方”，再回看假名。这里还不要求造句。

## 4. 在真实词形里辨认

比较`びよういん／びょういん``きて／きって``ビル／ビール`。先只找字形差异，再看解释，不用猜未教词义。

<details><summary>解释与附带词义</summary>

びよういん（美容院）中的よ是大字，是美容院；びょういん（病院）中的ょ是小字，是医院。きて是“来”的一种形式，きって作为本课名词是邮票。ビル是大楼，ビール是啤酒。后两组附带词义用于说明不能忽略小っ和ー，不计作本课主动记忆词。

</details>

## 5. 数字与短标签

先认 0 ゼロ、1 いち、2 に、3 さん、4 よん、5 ご、6 ろく、7 なな、8 はち、9 きゅう、10 じゅう。十一是じゅういち，二十是にじゅう；100 ひゃく、1000 せん、10000 まん。某些数词和量词组合会变音，后面按完整表达教，不要求从这张表猜一切读音。

数人时先记两个整块：一人／1人（ひとり）一个人；二人／2人（ふたり）两个人。不是いちひと、にひと，后面课程的二人指两人。

> 1時間　2時間　日本語　学校　バス

读法：いちじかん、にじかん、にほんご、がっこう、ばす。意思是一小时、两小时、日语、学校、公交车。这里`時間`是时长，不是几点。

最后回看`がっこう／ガッコウ``べんきょう／ベンキョウ`：读的是相同的词，换了字形。明天开始读句子；今天的字形表一直可以回看，但后续复现会逐步减少依赖。

## 场景串读：把今天的词连成意思

与词表交替使用：看一组词，读对应短句，再遮住中文读一次。正文和旁注都在“词语与场景”时段内；第3天只做名词标签辨认。这里的对译是教学反馈，不是外部测试答案。

**1.** 月・星・空

<details><summary>展开本句意思与用法</summary>

月亮、星星、天空；把天空里的事物并排辨认。月在这里读つき。

</details>

**2.** 山・海・土

<details><summary>展开本句意思与用法</summary>

</details>

**3.** 木・花・風・火

<details><summary>展开本句意思与用法</summary>

树、花、风、火；观察木与本的区别，不靠汉字猜日文读法。

</details>

**4.** 先生・勉強・学校

<details><summary>展开本句意思与用法</summary>

せんせい＝老师；べんきょう＝学习；がっこう＝学校。这里仍是标签，不是句子。

</details>
