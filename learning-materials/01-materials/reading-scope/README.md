- **人物与关系**：姉、弟、妻、夫、息子、両親、親戚、人物、友人、表情、態度、感情、寂しい、悲しい、納得、誤解、信頼、相談、応援等。
- **信息与判断**：質問、経験、意見、原因、影響、条件、例、例えば、種類、特徴、判断、比較对应的比べる、含む、選択、証拠、予想、範囲、解決等。

## 这次与旧选材方法的实际区别

**成熟资料提供知识内容，编辑决定具体教学义项，语料提供核对证据。** 三者各自承担一部分判断；没有一个排名或分级自动决定全部课程。

1. **复用现有课稿，不再次从零挑一套。** 现有874个词形＋读音表项，经已有明确异写关系归为868组，保留已教有效内容。加入的词与现有正式表项对账后，新增487组表项范围。487不等于487个完全未见的新概念，正文已有解释的情况须保留。
2. **逐项选择资料内容，而非整包导入。** 从既有Kaishi明确引用447条卡片义项，其中不少与旧课/79项重合；再整合原79项和92项Irodori补充。具体选择固定在[decisions.json](decisions.json)。未选择的Kaishi、Irodori和旧1308候选继续留资料池，不自动入课。
3. **不再要求一个词同时挤进多个体裁的前N名。** 星期序列、时间关系、自动/他动、亲属和基本位置等需要成组完整教学；单个词在一种材料较集中，不构成删去理由。词频较高也不自动使全部义项、角色语变体和语法表面形都成为独立必背词。
4. **用“具体义项＋关系”替代孤立词头。** 例如時間がかかる、お金がかかる、電話をかける、めがねをかける分别说明对象与含义；不能教过“挂”就认定这些用法全教了。自动他动、开始/持续/完成、原因/条件/观点等也明确为教学关系。
5. **评分材料不参与选词。** 构建程序只读冻结教材、现有课文、逐项内容决定及独立JEV核对资料，不读测试原文、答案、成绩或缺词榜。新范围没有按旧20段的分数调参数。

这套范围是本项目的编课决定，不冒充“官方1355词标准”，也没有以词数推出90%理解率。其优点要通过实际编课与新材料验证体现，不能在选材阶段先宣布成功。

## 依据及使用限度

既有Irodori提供可定位的词汇、场景和句型；GENKI官方学习项目表与Tae Kim补结构核对；Kaishi提供已整理的读音、中文义项和例句。Jiten、BCCWJ与CEJC的已有审查保留作常见程度、语域和词元问题的证据，原始频率资料无需重新收集。

新增核对只补选材依据缺口：

- [日本語教育語彙表 JEV](https://jhlee.sakura.ne.jp/JEV/)结合书面语料、教材语料及教师难度判断。此次实际读取其公开表，按明确写法/读音核对已选词，**难度等级不作为准入条件，也不等于重要性排序**。原表保留在忽略缓存，仓库只保留汇总核对结果与恢复入口，不再分发原数据。
- 松下等（2025）的[初级词汇选择研究](https://doi.org/10.15084/0002000522)在[出版方摘要](https://ndlsearch.ndl.go.jp/books/R000000025-I011290006868218)中明确同时考虑频率、分布、词汇体系、学习用途、多义及理解/产出的区别。这支持调整旧的单一门槛方法；该论文没有为本项目词数或21天效果提供保证。原PDF本机字体读取不可靠，本次只采用可读摘要，不声称完整复现其11步研究。

来源与冻结输入见[sources.json](sources.json)。没有把尚未取得的GENKI完整单词索引或QUARTET内容说成已纳入；没有重新下载旧教材全集。

## 已解决的具体误判与释义问题

- 無料、いらない：第16课已解释；补词条、辞书形和复现，不重复当全新概念。
- 去年：第6课已有读音和释义；寒い、暑い：第17课已有解释但读音/回链不完整；指：第20课已有ゆび和整句义。已记录实际行号。
- 広い、薬、弟等已有场景或整句解释，需要补足读音、词表和教学衔接；倒れる只作为倒す的对比出现，不能算完整独立教学。
- 申し訳ない：本期教道歉，不沿用“无法原谅”作为此表达的释义；ちゃん讲亲昵称呼关系，不只音译。
- 一方：教一方、另一方面和对照关系，不以“单行交通”充当一般义；予想与期待、評価与正面认可、使用与用法分别纠正。
- 以上：包括相等；保留原正文正确对比，下一步修词表矛盾。使役授受和待て原来已教，语法表注明保留/完善，不重新报成完全缺失。

这些纠正已经写进**下一版内容范围**，尚未覆盖旧课。所有已选词的有效义项依次取：`usage-targets`明确范围 → `supplements`自写义项 → 原79项的审查义项 → v3正文及词表 → 明确选中的Kaishi卡片义项。`WORDS.tsv`只指向有效一层；其他记录是来源，不维护几份相互争夺权威的释义。

## 与21天课程的关系

约束仍为21个学习日、每天至多60分钟。这里先确定要教的知识；没有把1355组均分成每日背词任务，也没有增加课外必学。前三天假名、后续语法/搭配/复现/连续阅读都必须计入时间。

**487组新增表项范围与64个主干单元会增加编课压力；本次没有测得它们能在21小时内掌握。** 下一步要复用旧课、合并同义项与规则性变体、处理首次解释和复现，编成实际每天可读的内容；完成课稿后再计时/验证。排不进预算时必须回到具体冗余与教学设计解决，不能偷偷增加天数、把内容藏到课后，或删掉必要基础后仍声称达标。

此次没有新学习成绩。旧约70%仍属于v3；不是本范围的测试结果。
