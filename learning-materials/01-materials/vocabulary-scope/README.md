# 番剧与漫画常用词 v3

2026-11-13。**777 个优先教学组**，已全部编入[21天课程](../../02-course-design/README.md)，每组有词表读音、教学义和当课日文用法。完整词汇与双榜排名：[WORDS.md](WORDS.md)。

## 为什么重筛

第四轮发现“双榜同时前1,000”会漏掉单一媒体常见的日常词，如妹、髪、猫、高校、あたし。现在改为**番剧或漫画任一榜前1,000**，仍逐条审阅，而不是全部导入。沿用同一份冻结词频资料，没有从第五轮考题反向选词。

原始排名来自[Jiten按媒体词频下载](https://jiten.moe/frequency-dictionaries)，冻结快照记录3,863部番剧、1,279部漫画；CSV分别213,416和273,493行。是一个项目的两个分库，不是两家独立验证。CSV给排名，不给原始次数。原文件、许可、日期、哈希见[sources.json](sources.json)。

[公开统计实现](https://github.com/Sirush/Jiten/blob/aa4d1d484e1e9a5ae8a092757f5f177bff128ac4/Jiten.Core/JitenHelper.cs#L980)按 log(1+出现次数)×出现作品数排序，降低一部作品重复某词的影响；[导出实现](https://github.com/Sirush/Jiten/blob/aa4d1d484e1e9a5ae8a092757f5f177bff128ac4/Jiten.Core/YomitanHelper.cs#L86)提供写法和读法。下载文件未声明部署代码版本，因此不声称已重算服务器排名。

## 逐条决定与数量

1,161 个候选＝**777 核心组＋230 语法表面形式＋100 合并形式＋54 暂缓项**。相比原605核心组增加172组；与已有课程对应后，实际新增588个词表行。两个数字分母不同，不能混说。

- 正常词：人物、日常行动、情绪、关系、时间、常见剧情动作优先。没有因“战斗”不是日常生活就全部删去，因为用户要读剧情。
- 明确合并：全く／まったく、綺麗／きれい等；异写按明示关系合并，不自动合并所有同音词。方的ほう／かた保留两个教学组。
- 语法：助词、活用、缩约等另归[GRAMMAR.md](GRAMMAR.md)。230是表面形式数，**不代表230个独立语法点全部新教**。
- 暂缓：出版发行信息、部分专名、片段发声及无法仅凭词频消除的歧义；如発行、株式会社、コミックス，不因排位靠前就塞给初学者。详细理由见[REVIEW.md](REVIEW.md)。

任一榜前1,000是本轮可审查的编辑边界，不是已证明的最佳阈值。完整阈值敏感性统计在[summary.json](summary.json)。不能把未入选等同于永远无用；后续跨作品反复出现才考虑升级，不根据单篇漏词直接扩充。

## 词义和课程责任

词频只证明词形排名，不提供义项级出现率。基础释义参照既存Kaishi／Irodori资料，缺项和口语义由编者校订。selection.json拥有选词决定；课程lessons拥有具体教学语境、补充义项和时间安排。例如抜ける在课程里明确教髪が抜ける＝头发脱落，不能只拿词库中的“退出团体”解释该句。

课程还保留车站、基础课堂词等支撑项，所以全课词形数量不等于777。777全部有课内落点，只证明编入了教材，不证明学生全部学会或能理解90%生肉。
