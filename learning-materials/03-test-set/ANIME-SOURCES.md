## 选源结论

| 资源 | 实际检查结果 | 本轮使用方式 |
| --- | --- | --- |
| [Ajatt-Tools/kitsunekko-mirror](https://github.com/Ajatt-Tools/kitsunekko-mirror) | 社区收集的 SRT/ASS；可查到日文、作品目录、文件名和时间轴 | 使用四个 SRT 的外部原文定位，固定版本，不复制整集正文进项目 |
| [Japanese-Dialogue-Dataset](https://huggingface.co/datasets/JustANormalTinkerer/Japanese-Dialogue-Dataset) | 清洗去重的单句集合；本次预览出现 `source` 为《100-man no Inochi...》而 `source_file` 指向《Sekai Saikyou no Majo...》的对应冲突 | 不直接作为测试集；失去连续上下文，来源标签也须重新核对 |
| [AnimuSubtitle-JP](https://huggingface.co/datasets/KaraKaraWitch/AnimuSubtitle-JP) | 保留 ASS 的公开数据；卡片对正文权利仅写暂定 ODC-By，并承认字幕属于动画内容 | 未选用；不把数据卡标签当成版权方授权证明 |
| [JESC 项目代码](https://github.com/rpryzant/JESC)及[论文](https://arxiv.org/abs/1710.10639) | 真实字幕平行语料研究；本轮项目数据主页反复超时，未核验到可直接使用的连续集数样本 | 保留候选，不计入已取得数量 |
| [Hulu 官方字幕目录](https://news.hulu.jp/closedcaption/) | 有字幕功能的节目清单 | 仅发现来源，不计样本 |

公开可访问与开放许可是两个事实。这次已解决“找不到字幕正文”，没有声称已经解决“字幕可以直接随商业产品分发”。目录和正文来源不混用，原文与评分也分开。

## 原文可追溯到什么程度

四个文件固定到提交 `619b935cb062b7c122cd25614f02a3ac919c285b`。来源记录包含原文件名、Git blob SHA-1、整文件 SHA-256、字节数和字幕数；每个片段包含集数、连续 cue 编号、首尾时间、原文件行号和规范化文本 SHA-256。

本轮已验证四个文件字节与 Git blob 一致，12 个片段的行号、时间范围、字数和内容哈希可重算。官方分集页核对作品与剧情归属，不替代字幕逐句准确性核对；时间码只适用于所选字幕版本，不保证适配别的平台视频。

保留说话者、口语错说、重复台词、停顿和音效标记，不把原话改成标准教材句。片段避开主题曲歌词；少量纯音乐／音效标记保留在原定位范围，并在评分范围说明。仅去掉显式 ASS 排版标签，不靠全删括号来清洗。
