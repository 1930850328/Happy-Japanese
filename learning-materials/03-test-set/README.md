## 数据与校验

- `target-profile.json`：历史番剧／漫画报告的类别、权重和聚合规则；第6轮通用阅读诊断范围另冻结在该轮 `freeze.json`。
- `sources.json`：作品、版本、类型、系列隔离组、来源与偏差。
- `samples.json`：片段边界、当前split、原文位置与哈希；新漫画页记录在 `locator.pages`。
- `answers.json`：与原文分离的意思单位及原文依据；当前均为草稿。
- `CATALOG.md`：由数据生成的阅读入口。
- `materials-baseline.json`：11月11日的历史教材快照，不覆盖、不随现在的教材更新而刷新。

在仓库根目录运行：

```sh
python3 learning-materials/03-test-set/tools/validate.py --metadata-only
python3 learning-materials/03-test-set/tools/validate.py --metadata-only --write-catalog
```

公共检出默认只验证登记信息和已有文件；不会把未下载的旧原文算作已核验。完整旧资产都恢复到本地后可去掉`--metadata-only`。通过[跨设备入口](../START-HERE.md)下载字幕和新漫画后，追加 `--subtitle-dir <目录> --image-dir <目录>`：校验全部14个SRT文件的字节、Git blob、片段正文与时间范围，以及40张外部漫画图像的字节与哈希。临时文件名在数据里；文件不会由校验器自动下载。

`--check-material-baseline` 单独比较当前教材和旧快照。教材已经过多轮重筛和重编，与旧快照不同是预期的版本变化，不应导致测试集完整性检查失败。每轮课程评估仍应冻结自己的教材/课程版本，历史评估的课程快照校验保持有效。

第5轮已核验12份新旧字幕、32张外部漫画图以及全部本地资产，课程重编和新原文对照记录另存。仅本地研究资料变化，未接入应用、提交或发布。数据校验通过不替代日语评分审校。
