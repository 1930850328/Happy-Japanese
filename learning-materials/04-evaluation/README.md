# 第 1 轮：教材与课程可测性检查

日期：2026-11-11。结论：**当前版本未通过正式学习验证的准备检查。主要问题是课程正文尚未完成，其次是词汇和结构的教学安排尚有缺口。**

本轮实际处理了 24 个开发片段、11 个来源隔离组、8 类文本，做词形检索和 8 个句意要求的溯源。没有进行学生学习实验，也没有用模型原有日语能力冒充学习成果。理解率为“未测”，不是 0%，也不是下面的词形命中率。

## 1. 先确认实际交付了什么

| 检查对象 | 结果 | 对测试的影响 |
| --- | --- | --- |
| 教材资料 | Kaishi 1,500 条；Irodori 4,246 条词汇出现记录；假名与语法参考资料存在 | 这是可选教学内容，不等于学生已学会 |
| 课程 | 21 天蓝图、1 个第 9 天的部分教学单元；没有完整的 21 课正文 | 不能执行“从零完成全部课程后阅读”的实验 |
| 逐词安排 | 没有完整词条到课次及语境的分配 | 无法知道毕业时究竟教过哪些词义 |
| 60 分钟限制 | 设计中的时间预算满足限制；没有实际学习计时 | 不能证明设计内容能在时限内学完 |
| 参考答案 | 24 份草稿、127 个意义单元；无独立复核通过记录 | 当前只能做开发诊断，不能作为可靠成绩发布 |
| 本轮测试正文 | 24 / 33 个开发片段；9 张未有核对转写的漫画图未做自动词形分析 | 图片未计入，不按零分处理 |
| 保留集 | 本轮未加载 13 个保留片段的正文 | 本轮修改不能声称在保留集上提高 |

上一轮交付的是设计，不是可完整接受学习的课程。这个交付缺口由编课环节负责，不能靠给模型一句“假设你是小白”补上。

## 2. 已跑出的词形检索结果

完整逐片段结果和候选词见 [lexical-results.json](lexical-results.json)。这张表不能换算成“学生看懂了多少”。精确匹配既会漏掉字形变体、复合词，也会误把同形异义当作已经覆盖；现代书面文本、旧文学、字幕的分词表现也不同。当前样本不是随机抽样，类别数量不均，不能推断整个生肉市场的比例。

本轮共生成 546 个未命中的“词元＋词性”候选，不是确定缺少 546 个词。具体分三类处理：

| 例子 | 本轮证据 | 应采取的处理 |
| --- | --- | --- |
| 試験、部活、母親、合格、専門 | 两份词表中无同形独立词条；各在 2 个来源隔离组出现，分别为 4、4、3、2、2 次 | 列入内容候选，进一步核对独立频率来源、词义与已有表达；不能仅凭本轮频次宣布是通用高频词 |
| 居る、いう | 精确词形未命中，但对应的いる、言う已有词条 | 校对语境后处理字形/表达对应，不机械新增同义卡片 |
| られる、てる、ちゃう | 容易被切成动词，实际可能属于语法结构 | 前两类已从统计中排除；ちゃう仍可能残留误报，需要逐例看上下文，不当作生词批量加入 |

`いる` 还说明了另一种风险：资料中存在“存在”和“需要”相关词条，同一个表层形式命中不代表读对词义。后续课程安排必须落到具体义项和语境。

## 3. 句意检查揭示的教学问题

8 项详细记录见 [semantic-audit.json](semantic-audit.json)。这是“这句话需要教会什么”的溯源，不是假造的学生答卷。以下误读都是需要防止的风险，不是观察到的学生错误。

| 开发片段 | 必须读出的关系 | 本轮发现 |
| --- | --- | --- |
| manga-007 | `しか` 与否定一起表达“只睡了 3 小时” | 范围资料存在；课程还需把口语否定与范围组合教出来，不能逐字当作“没睡” |
| manga-009 | 合格义务，而非已合格的事实 | 义务结构有参考讲解；合格、試験缺同形独立词条，正文尚未安排 |
| manga-066 | 不打工就连生活也维持不了 | `なきゃ` 在这里接有明确后果；不能只教成孤立的“必须”口头表达 |
| anime-kon-02 | 若本月内不足 4 人加入，社团将被废止 | 必须结合条件、期限、人数和后文；不能读成已经废社 |
| anime-shirokuma-01 | 询问对方为什么不来，并含“为我来”的视角 | 授受讲解存在，但课程还没有把否定问句、人物视角合在一起教 |
| anime-shirokuma-03 | 说话者用“它刚动了”的证据否认标本说法 | `わけない` 讲解存在；不能只认出“标本”这个名词 |
| supercub-02 | 缺少交流，并不意味着讨厌母亲 | 需要区分否定解释与否定事实；现有课程仅用“わけ”概括，具体边界没展开 |
| daily-mercari-01 | 从发送交易消息开始计算等待时间，并结合未收到回应等条件 | 需要读对时间起点、条件和指令对象；不是知道“24 小时”就算读懂 |

**根本问题：教材来源已经收集，但“选定词义和结构 → 讲解 → 不同语境复现 → 撤掉提示”这段教学内容尚未真正交付。** 新增更多来源或直接让模型翻译测试文本都不能修复它。

## 4. 本轮修正与下一轮验收

本轮已修正统计方法：不再把分词器标出的非自立/接尾动词一律当作内容词；明确区分词形命中、材料有讲解、课程有教学、学生能理解。这个修正提高的是审计的准确性，**不是课程学习成绩的提高**。

下一版需先完成三个具体修复，不能只改这 8 句的答案：

1. 在 21 课正文中实际使用选定词条和义项，把首次教学与后续复现落到可阅读的内容；参考章节链接不能算作完成一课。
2. 为否定范围、条件及省略、授受视角、解释与事实的区别提供原创对比例句和连续文本。开发集只指出能力缺口，不把其原文或译文抄成训练内容。
3. 复核评分意义单元并完成可执行课包后，再开展学习测试。真实学习者结果单独记录；受限材料检查也单独记录，不能以模型自述“不懂日语”消除模型预训练知识。每类文本分别报告理解率，不用重复片段抬高总分。

本轮没有修改教材词表、课程内容、测试答案或应用。因未有学生试验，尚无“改课前后理解率”的对照结果。

## 5. 复跑与证据

输入版本与文件散列见 [run.json](run.json)。原文定位、散列与权利说明仍以第三部分为准，本目录不再复制完整外部原文。

在仓库根目录执行（需要既有临时抓取文件；它们不是永久交付依赖）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 learning-materials/04-evaluation/tools/prepare_inputs.py --captures /tmp/happy-japanese-test-set --output /tmp/happy-japanese-test-set/audit-inputs.json
node learning-materials/04-evaluation/tools/lexical_audit.cjs /tmp/happy-japanese-test-set/audit-inputs.json learning-materials/04-evaluation/lexical-results.json
PYTHONDONTWRITEBYTECODE=1 python3 learning-materials/03-test-set/tools/validate.py
```

如果临时抓取已被清理，应按 `03-test-set/sources.json`、`samples.json` 重新获取并校验散列；当前脚本不提供自动下载。原文变化或散列不匹配时会报错，不静默换题。逐句溯源结论由人工阅读式审查得出，未经过第二位独立审校者复核。

本轮验证记录：重建的 24 份输入散列全部匹配；第二次执行词形审计与保存结果逐字节一致；`run.json` 所列散列与报告本地链接通过检查；测试集校验器通过。这里验证的是文件、定位和审计可复跑性，不是教学有效性。
