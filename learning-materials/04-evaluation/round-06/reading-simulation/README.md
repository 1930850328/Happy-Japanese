# 学完现有21课后能理解多少：新手阅读模拟

**本次模拟内容理解得分约70%。** 使用原有21课，不增加79项或1308项候选；对上一轮20段原文逐段模拟复述，共181个意思单位。没有重编课程，也没有把词形覆盖换个名字当理解率。

设定：中文母语零基础者学完21课，能够记住并使用课内明确教过的知识；可以依据普通中文、上下文、漫画画面推测，不查课外词义。此结果是模型在上述设定下的编者模拟估计，不是实际学生成绩；理想记忆不证明真人能在21小时内掌握。完整规则见 [PROTOCOL.md](PROTOCOL.md)。

## 比例怎么来的

| 对原文意思的模拟理解 | 单位数 | 每项计分 |
| --- | ---: | ---: |
| 实质意思完整，人物、动作、肯否等关系正确 | 88 | 1 |
| 理解了部分实质内容，仍缺有意义的信息 | 77 | 0.5 |
| 核心意思未恢复或关键关系错误 | 16 | 0 |

**(88＋77×0.5)／181＝69.9%。** 这是允许部分理解折半的内容得分。若只问“有多少意思单位完整读懂”，答案是88／181＝48.6%，不能把部分理解全部算成看懂。两项同时保留，避免一个比例掩盖仍然读得断续的情况。

| 类别 | 意思单位 | 模拟内容得分 |
| --- | ---: | ---: |
| 番剧字幕 | 42 | 64.3% |
| 漫画 | 30 | 83.3% |
| 轻小说 | 39 | 62.8% |
| 日常办事说明 | 30 | 68.3% |
| 说明／科普 | 40 | 73.8% |

按类别列出的数值由 [results.json](results.json) 生成；总分按意思单位汇总，不是五类等权平均。语义切分与半分权重是本次评分约定，单位不能直接当作独立随机样本来计算总体置信区间。

## 新手实际理解成了什么

| 原文中的任务 | 受教材约束的模拟理解 | 判定 |
| --- | --- | --- |
| 校园漫画里女孩问有没有喜欢的人 | 能分清是女孩在问，男孩考虑回答喜欢的就是她；没有把心中猜测当已发生的告白 | 对应单位完整理解 |
| 同一段中男孩担心抢先告白 | 只知道担心自己的回答会影响女孩的告白，横取り所表达的抢先关系没恢复 | 部分理解 |
| 烹饪对白催对方搅蛋 | 知道是请求，也能凭中文认出卵，但不知道要求做什么动作 | 未理解，不因认识宾语给半分 |
| 日常票务说明 | 能理解选择时间、车次及按确认；遇到票种和“只办理某种合并票”的限制时，不能完整判断操作规则 | 易读指令得分，困难限制分别扣分 |
| 平凡人生的开篇评价 | 虽没逐字学过开头惯用表达，凭普通、人生及上下文能恢复平凡的评价 | 完整理解，不按生词扣分 |

全部181项的定位、模拟复述、分值、课程课次与推断／缺口见 [units.tsv](units.tsv)。文字定位按上一轮冻结的本地片段行号；漫画另有2个纯画面单位。排除纯画面项为124.5／179＝69.6%，不会改变约70%的结论。混合图文单位仍利用图像辨认说话者，不能称为纯文字成绩。

这里允许中文汉字和画面推断，因此该分数不能全归因于课程；本轮没有设置未学课程的对照，也没有模拟遗忘。小说、科普中有的汉字词未教，但可以猜到意思；日常假名词或口语惯用表达反而可能成为关键阻碍。

## 对前面判断的纠正

我之前交付了词形覆盖，没有交付用户要求的模拟理解指标；随后又把已经做过的选材、编课说成下一步，重复启动了错误方向。本轮补做的是缺失的验证。

课程证据复核还确认：使役授受的 `させてもらう`、`待て`、免费、以上包含相等，都已经在正文里教过。不能因正式词表或简略审查没捕捉到，就再次判为没教。具体修正见 [REVIEW.md](REVIEW.md)。

**现有课程提供了不少有效的基础，不能简单推倒重来。** 在理想记忆条件下，新手可读懂不少短对话和直接说明；较长叙事、具体动作词、复合表达及复杂办事条件仍使理解断续。本轮结果支持先定位这些缺口，再回成熟教材和独立语料核实其普遍性，不直接把本次考题漏词加入课文。

69.9%与此前49.4%或58.2%的词形匹配是不同指标，不能相减并称为课程进步。本次材料已经曝光，只是旧材料上的新增语义评估，不是新保留集或独立真人实验。
