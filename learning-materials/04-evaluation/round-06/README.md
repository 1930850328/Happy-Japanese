# 第6轮：通用阅读选材方案的跨体裁检验

**后续补做：[现有21课的新手阅读模拟](reading-simulation/README.md)。** 按181个意思单位记录模拟复述，内容得分约70%（完整理解88项、部分77项、未懂16项；部分折半）。这是课内知识理想记忆条件下的编者模拟估计，独立于本页词形覆盖指标；复核也纠正了对正文已教内容的漏判。

2026-11-16。**本轮没有证明“21天后读懂90%”。79项增补带来的词形匹配提升较小；把全部基础候选都计入后仍存在明显缺口。选材方案需要继续审查，不能直接当成已经有效的新课程。**

实际读取10个新作品／来源的20段原文，逐句核对其中40个意思单位。先冻结教材及抽样规则，再读取新材料；没有根据成绩换片段、补词或修改课程。21课正文仍为v3，本轮只检验上一轮提出的新教学范围。

## 同一批原文上的结果

| 类别（各2来源、4段） | 现有v3词表 | v3＋79项优先增补 | v3＋1308项基础候选 |
| --- | ---: | ---: | ---: |
| 番剧字幕 | 64.2% | 65.7% | 69.4% |
| 漫画 | 59.5% | 59.5% | 60.2% |
| 轻小说 | 45.0% | 48.9% | 55.5% |
| 日常办事说明 | 35.3% | 37.2% | 50.8% |
| 说明／科普文字 | 43.2% | 44.8% | 55.1% |
| 五类等权描述性平均 | **49.4%** | **51.2%** | **58.2%** |

精确计数见 [lexical-results.json](lexical-results.json)。分母共1098个符合旧评估口径的实词出现次数；先按片段、再按作品、最后按类别平均，不是把所有字混在一起算。+79为1.79个百分点提升；全基础候选为8.75个百分点提升。不能与第5轮不同原文上的48.1%直接比较改进幅度。

三组分别有872、951、1537个去重书写形式。1308是基础候选条目数，其中很多与旧课重合，合并后净增加665个书写形式。**后两列是假设词汇范围，不是已经编入21课、学会或在21小时内完成的效果。**

这张表统计正式词表的词形／词元匹配，不是看懂内容的百分比：助词、助动词等不在分母中；同形多义没有消歧；异写、部分活用和正文旁注也会漏报。它既不是理解率上限，也不是下限。40个意思单位是编者诊断，没有真人答卷、独立评分者或完整答案复核，因此不产生“模拟小白理解了多少”的成绩。

网页每块从段落边界开始，累积至少220字符；第二块从不重叠且累计偏移至少600字符的首段开始，原文较短时取第一块之后的下一段。精确位置和哈希见 [samples.json](samples.json)，公开URL、源文件版本、图像哈希和输入问题见 [sources.json](sources.json)。全测试库入口：[原文目录](../../03-test-set/CATALOG.md)。

字幕使用固定Git提交的公开镜像，并核对原SRT的Git blob SHA；官方分集页只核对作品信息，未把剧情简介当字幕。漫画共8张完整原图，保留标题页和无对白页，没有为提高分数替换。图像本身也承载信息，这部分不能由转写词频评分。网页去除导航、注音和重复移动版组件，保留选中正文中的困难内容。

10个隔离组均不同于本轮开始前的32组；《徒然チルドレン》与旧漫画同作者，因此只是新系列，非新作者。两个漫画同出版社、两本轻小说同平台，且以开篇为主。每类仅两个来源，是便利抽样；不能据此给全日语阅读能力估计置信区间或宣称代表所有体裁。说明／科普类别也没有覆盖新闻、论说文、商业邮件等全部书面用途。

本轮五类等权是冻结的诊断协议，保留旧 `target-profile.json` 的番剧／漫画50:50历史口径。结果文件的 `split: holdout` 表示首次运行时的身份；用后20段已在中央测试库登记为回归，不能再当新考试。

## 40项整句核对说明了什么

完整逐项记录：[semantic-review.tsv](semantic-review.tsv)。每段取前两个有实质内容的完整意思单位，记录中文含义、旧课依据、新范围能解决什么及仍缺什么；没有按容易程度选择单位。

1. **增补确有帮助，但帮助集中且有限。** 卵、大学、会社、住所、無料、午前、条件、比べる等在不同新来源中出现；79项增补在这两部漫画中没有直接词形收益。不能据此删除它们，也不能据此只补漫画漏词。
2. **完整表达与关系解释仍缺。** 何ということもない不能逐字拼成句义；させてもらう需要说明谁行动、谁许可；漫画中的猜测不能读成已经发生的告白；票务条件需要同时看例外、时限及操作顺序。新范围中的理由并列、量词、命令、惯用表达等功能有价值，但功能名称进入清单不等于完整教学已经完成。
3. **现有匹配器会把一部分已教内容判成未知。** 旧课第7课出现うれしい／嬉しい，第10课出现わかる／分かる，正式词表单一写法可能漏掉另一写法；使える也不能只靠分词器基本形自动归回使う。因此不能把全部未匹配项列为教学缺词。另一方向，同形词匹配成功也不能保证学生知道本句词义。

本轮只记录这些问题，没有把测试原句或漏词回灌进教材。

## 选词方法暴露出的根本问题

测试后用已冻结、独立于测试的BCCWJ词频回查，见 [independent-gap-check.json](independent-gap-check.json)。原方案要求“5个书面领域至少3个进入前3000”，这个交集偏好各领域都常见的词，却容易漏掉只在某些普通生活用途里集中的词：

- 現象只在书籍、问答两个领域进入前3000；雲也只有两个领域；列車、配達各只有一个领域。它们不满足三领域交集，但不能因此被等同于专业冷僻词。
- 操作满足跨领域阈值，却因为未被已有成熟教材候选池承接而归入扩展候选，说明词频与教材池之间的决策边界也会漏项。
- 某些表面词查不到同名词元还涉及异写和词元归并，不能把“没有精确命中”写成“不常见”。

这些是解释筛选机制的诊断例子，**不是已经批准加入教材的新清单**。下一次选材应独立核对成熟教材的完整功能／情景覆盖、领域内频率及跨领域分布，处理异写和词义；不能不断调整前3000这个阈值，直到当前20段达到90%。本轮不足以推导还应加多少词，也没有证明增加词数本身能解决21小时学习效果。

## 输入敏感性与一致性

《あの花》的SRT存在相同文本在相邻／重叠时间码连续显示的问题。主结果保留冻结窗口原记录；另移除明确记录的18条连续重复cue重算，五类平均由49.43／51.22／58.18变为49.07／50.91／58.08，结论不变。只核查文本和时间码，没有听音确认。见 [subtitle-sensitivity.json](subtitle-sensitivity.json)。

教材35个文件、输入及规则都以哈希冻结。`initial-test-manifest.json` 保留首次评分前版本；之后为兼容中央校验器补充历史split/source_id并登记回归，变更记录在 `test-manifest.json`，未修改原文、词表、匹配、权重和分数。测量结果与诊断文件哈希见 `result-manifest.json`。

## 在另一台设备复算

先按 [START-HERE](../../START-HERE.md) 安装独立工作区依赖。在仓库根目录运行：

```sh
node learning-materials/04-evaluation/round-06/evaluate.cjs --features --check
python3 learning-materials/tools/workspace.py check
python3 learning-materials/tools/workspace.py regression --current
```

第一条不需要第三方原文缓存，会用无句序的特征计数逐段重算并对照本轮结果。只支持这三个冻结词汇范围；教材或特征被改动会拒绝重跑，不支持把任意新词填进去打分。后两条检查工作区一致性并复跑第5轮旧样本，不是新增学生实验。

本机原件齐全时还可运行：

```sh
learning-materials/.venv/bin/python learning-materials/04-evaluation/round-06/prepare.py --check
node learning-materials/04-evaluation/round-06/evaluate.cjs --check
learning-materials/.venv/bin/python learning-materials/04-evaluation/round-06/subtitle-sensitivity.py --check
```

原文保存在忽略的 `.cache/round-06/`。公开仓库不含整篇网页、字幕全文或漫画完整转写；新设备做整句审查仍需打开已记录来源。`fetch-tests` 可恢复中央登记的字幕和漫画图，不能恢复本轮全部网页快照及私有人工转写，不应把特征重跑称为整句理解的一键复现。

实际验证记录见 [validation.json](validation.json)。本轮未改教学正文、应用或部署，未提交或推送。
