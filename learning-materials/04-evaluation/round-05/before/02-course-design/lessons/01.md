# 第 1 天：把平假名认成词

今天不学句子。目标是看到平假名，能借表认出读法，再把字连成一个词。无需写字或大声朗读。读音在本课帮助建立稳定对应，不考听说。

时间上限：认字 25 分钟；乱序辨认 12 分钟；词内辨认 10 分钟；回看与复现 8 分钟；休息 5 分钟。到 60 分钟停止，不另留作业。

先修：无。材料依据：[平假名](../../01-materials/reader/tae-kim-zh/hiragana.html)。本课表、任务及以后课文均为教学编排，不是测试集原文。

本课从零开始，没有前课背词任务。

## 1. 先建立字形对应

先看一行，再用纸遮住右栏辨认。罗马字只是本课的读音索引，不是日文的替代写法。a、i、u、e、o 大致对应“啊、衣、乌、诶、哦”，不要把汉字谐音当作精确发音；し、ち、つ等尤其不宜用中文硬套。阅读课暂不纠音。

| 平假名 | 读音索引 |
| --- | --- |
| あ い う え お | a i u e o |
| か き く け こ | ka ki ku ke ko |
| さ し す せ そ | sa shi su se so |
| た ち つ て と | ta chi tsu te to |
| な に ぬ ね の | na ni nu ne no |
| は ひ ふ へ ほ | ha hi fu he ho |
| ま み む め も | ma mi mu me mo |
| や ゆ よ | ya yu yo |
| ら り る れ ろ | ra ri ru re ro |
| わ を ん | wa o n |

共 46 个基本字。现代助词を通常读 o；ん是一拍的鼻音，后面没有额外元音。は、へ作为助词时另有读法，第 4、5 天会随句子说明。

每看完两行就暂停，用手指分别找到：あ／お、き／さ、ぬ／め、ね／れ／わ、る／ろ。它们不是同一个字的字体变化。观察结尾有没有回环、短横及交叉位置，再回到整字辨认。不要一口气机械顺背十遍。

## 2. 今天的词

表中“读法”与词形相同，先把每个字定位到上表，再连成一个词。

| 词形 | 读法 | 本课意思 |
| --- | --- | --- |
| あさ | あさ | 早晨 |
| いえ | いえ | 家、房子 |
| いぬ | いぬ | 狗 |
| ねこ | ねこ | 猫 |
| ひと | ひと | 人 |
| ほん | ほん | 书 |
| やま | やま | 山 |
| そら | そら | 天空 |
| くるま | くるま | 车 |
| わたし | わたし | 我 |

这些词先用假名学，后续出现「本」「人」「私」时，会明确连接到同一个词，不算重新学一个意思。

## 3. 换顺序辨认

第一轮看字，不看表，指出读法；不认识就回表查一次。第二轮只读刚才犹豫的字，每个读对一次就往下走。

> ぬ　わ　さ　ろ　い　む　へ　き　の　え　る　せ
>
> め　ね　お　れ　す　そ　ん　ひ　ゆ　あ　と　ま

<details><summary>展开核对</summary>

第一行：nu、wa、sa、ro、i、mu、he、ki、no、e、ru、se。

第二行：me、ne、o、re、su、so、n、hi、yu、a、to、ma。注意ぬ和め、わ和ね和れ、ろ和る的区别。查表不是扣分，目的是把错误对应及时改正。

</details>

## 4. 在词里辨认

读下面词串，先确认字，再在心里说出词义。中间的空格只用于本课，真实日文通常没有词间空格。

> ねこ　いぬ　ほん　いえ　ひと
>
> そら　やま　くるま　あさ　わたし

<details><summary>展开词义核对</summary>

猫、狗、书、家、人；天空、山、车、早晨、我。能按意思指出“交通工具”和“早晨”，说明开始把字形连到词义；这不是句子理解测试。

</details>

最后遮住中文，自己找出「ねこ」「ひと」「くるま」。停顿可以，但不要仅凭词在列表中的位置猜。明天混入片假名后还会复现平假名。

## 5. 收束

今天介绍完 46 个字，不要求一次达到自动识别。用最后 8 分钟回看最容易混的两组，再读一遍第 4 节的词串，然后结束。不能把“全表看过”标成“已经熟练”。
