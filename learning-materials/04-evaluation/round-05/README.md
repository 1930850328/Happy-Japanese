# 第5轮：把优先词与完整表达编入21天，再换作品验证

日期：2026-11-13。**已完成本地课程重编和新作品核查。同一批新原文上，旧课程正式词表的内容词词形匹配率为28.2%，新版48.1%，提升20.0个百分点；仍未证明21天读懂90%。** 这是教材范围的改善，不是学生理解成绩。

## 实际改了什么

1. 选词从“两榜都进前1000”改为“番剧或漫画任一榜进前1000，再人工分流”。冻结的双榜并集1161项，逐项归为777个优先教学组、230项语法表面形式、100项合并异写、54项暂缓片段。优先组比旧605组增加172组，原605组全部保留。门槛是可审阅的编辑选择，不是已证明的最佳词数。

2. 777组全部写入实际课文的词表，并有当课日文用法；此前未编入的清单现在进入教学正文。课程词形＋读音条目由286增至874，含假名／汉字重复和教学支撑词，不能叫874个独立词义。正文增加场景串读、中文反馈和必要旁注，777项逐一能追到首次教学课次。

3. 补全表达，而非只给孤立词根：第8／17天てくる・ていく；第10天おかげで・せいで・からこそ；第12天うちに；第14天きる・きれる・きれない；第18天确认搭配与缩约、どころではない；第19天三类わけ否定。都有解释、对照与反馈。

入口：[完整21天课程](../../02-course-design/README.md) · [777组清单与排名](../../01-materials/vocabulary-scope/WORDS.md) · [逐组当课用法证据](../../02-course-design/context-review.json) · [语法来源](../../02-course-design/EXPRESSION-SOURCES.md)。

## 60分钟如何分配，以及尚未解决的负荷

前3天保留假名入门；第4—21天每课复现10分钟、词语与场景21分钟、语法12分钟、带读与换文核对12分钟、休息5分钟，共60分钟。新增场景放入原预算，没有额外课后背词。到点停止，未完成必须记未完成。

**每天最多59个新词形，复现最多156个词形；这个安排还没有真人计时证据。** 文件检查只证明预算相加为60、内容实际写入，不证明初学者能在60分钟内吸收完。因此本轮完成的是可试学的完整课稿，不能把全课稿词表覆盖当作21小时后已经掌握的词表。这个时间负荷问题仍未解决。

## 整句检查：改进在哪里，仍卡在哪里

按预先规则，每段取前两个完整述谓发言／旁白单元，连续字幕合并，跳过称呼与纯反应，共32个诊断单位。每个记录中文意思、旧／新词表证据、语法定位及剩余缺口；见[semantic-audit.json](semantic-audit.json)。这只是编者支持度核对，不是32道真人答题，也不是全篇评分标准。

另做4项明确标记为探索性的迁移核查，不拿它们凑成绩：

| 新原文中的短锚点 | 现在能从课里得到的解释 | 仍需什么 |
| --- | --- | --- |
| 数えきれません | 第14天解释不能全部完成，可读出数不完 | 数える尚不在正式词表 |
| 腐敗しきっている | 第14天解释达到极限，可读出彻底腐败 | 腐敗的词义 |
| 直してくる | 第8天解释去做某事后回来 | がよい的命令语气未完整教 |
| 悩んでるうちに | 第12天解释过程中发生变化，可区分犹豫期间与趁机 | 悩む、乗り遅れる |

这说明新增结构有迁移用途，也说明“结构会了”仍可能被内容词挡住。固定32项里，自我介绍等句子原课程已有支持；方言食ぶっか、礼貌省略お決めに、わかんなかった缩约仍需补足，不能把所有新遇到的句子都说成新版解决了。
