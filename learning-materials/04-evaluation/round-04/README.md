# 第4轮：番剧／漫画新原文测试

日期：2026-11-13。结论：**605词清单扩大了对这批原文的词形覆盖，但现有课程还未纳入它；即使把它与课文合并，内容词覆盖仍约一半，缺口不只在专业词。当前结果不支持“21天后读懂90%”的承诺。**

本轮实际读取并检测了8部作品的16段原文：8段字幕、8段漫画（16张原页），未跳过漫画。课程和选词在计算前冻结，测试中未改课、未补词。原文位置以[测试目录](../../03-test-set/CATALOG.md)为准，版本与哈希见[run.json](run.json)。

## 2. 查清楚了哪些缺口

### 选词门槛漏掉单一用途里的常用词

当前规则要求两个媒体的名次均≤1000。重新查冻结的词频CSV后，以下条目均未进入605清单：

| 词 | 番剧名次 | 漫画名次 | 问题 |
| --- | ---: | ---: | --- |
| あたし | 1370 | 572 | 漫画常见自称被另一类门槛否决；原文还用アタシ |
| 妹 | 1096 | 915 | 家庭关系词被排除 |
| 髪 | 1339 | 957 | 外貌/生活词被排除 |
| 猫 | 1667 | 951 | 日常动物词被排除 |
| 高校 | 1900 | 926 | 校园词被排除 |
| 仲良く | 1587 | 900 | 人际相处表达被排除 |
| 野郎 | 929 | 1600 | 番剧较高频的粗口称呼反被漫画门槛否决 |

完整原始名次（含重复记录）与数据哈希见[frequency-diagnostics.json](frequency-diagnostics.json)。这里证明的是**交集规则造成的遗漏**，尚未证明改用简单并集就是最佳课程。

另有宿題、試験、合格等场景词，两类排名都在约2800–3800。它们说明只截最顶端高频表，仍可能无法读完普通校园场景。也不能把每次遇到的词都抬成核心：勤務在两部作品出现，但两类名次为10307、8711，应保留为用途候选。

### 认识组成词不等于学过整个表达

对16段各选1个诊断表达，核对原文与具体课文行。结果有已讲解、部分支撑、关键用法缺失三类，逐项见[semantic-audit.json](semantic-audit.json)。这些是教学依据检查，不计为学生答对/答错。

| 原文中的表达 | 应读出的关系 | 当前课程情况 |
| --- | --- | --- |
| 飼うわけにはいきません | 因现实条件不能养 | D19讲其他わけ结构，没讲わけにはいかない |
| その日のうちに | 当天之内归还 | D10有前后顺序，没有うちに这个期限用法 |
| 食べきれなくて | 无法全部吃完 | D14有可能否定，缺少～きる的完成义 |
| それどころじゃねえ | 顾不上那个 | D18有口语否定，缺少整个固定表达 |
| からこそ | 正因为如此才…… | 因果已讲，强调部分仅在候选语法表，未进课文 |
| 確認とっといて | 请先向对方确认 | 缩约已有，確認を取る搭配没有展开 |

同时确认了已有的有效支撑：しか＋可能否定、なければ条件、なくちゃ的义务省略、ことになった的事态结果等都有明确讲解。问题不是“全部语法都要重写”，而是补齐可迁移的表达、具体词义与搭配。

### 有些“缺词”其实是统计或书写问题

- 初算误把字幕角色名「える」等拆为普通词；已依据原文标注排除，规则逐项保存在[masking-manifest.json](masking-manifest.json)，读者看到的原文不删除这些内容。
- 「なのに」已在D10讲解，不能因它未匹配内容词清单就新增一张词卡。
- 「全く／まったく」「綺麗／きれい」属于书写对应；きれい已在D7。不能把每个未匹配字形都当作完全陌生的概念。
- 「うつ／だい／ちょ」等残留中有口语分词噪声。自动未匹配清单是待复核候选，不是已确认漏教清单；也未用汉字猜义、同音或模型翻译给匹配率加分。

## 3. 这轮改进了什么，下一次改什么

本轮完成的是测试：将漫画原图转写纳入计算；逐张回看16页，在最终统计前修正《カナコ》三处转写问题；清除角色标签干扰；用同一原文比较当前课程与选词方案；将缺口分为选词、整体表达、异写与统计误差。**没有在读完试题后把缺词塞回清单再给自己重测高分。**

课程下一版应先修选词规则：通用核心之外，允许番剧或漫画中单类高频、跨作品出现的日常词进入用途层；再用独立语料验证场景词的价值。语法补完整表达和搭配，而非只增加零散表层词。605清单需要真正编进21课，并保留旧课中有用的内容。21天、每天≤1小时的约束本轮未调整，也尚未做真人计时学习。

本轮8段原保留材料已用于诊断，全部转为回归。当前测试库为8开发、54回归、0保留；后续新课程必须另取作品评估。四部新漫画仍来自同一出版社的短页/四格开篇，四部番剧各只取一集，不能把这16段当作整个市场的代表。

学生“读懂多少”的百分比本轮仍未测得。这里验证的是教材是否提供相应知识，模型自身翻译能力没有被当成零基础学生的成绩。

临时原文若被清理：字幕按测试库固定提交及cue范围恢复；漫画从原页重新转写，按[transcript-manifest.json](transcript-manifest.json)核对。本文及仓库没有复制外部全文；因此漫画转写重建仍需人工核对，不能声称脱离外部原文也能一键复现。分词版本为项目既有kuromoji 0.1.2；改版本、原文、课程或排除规则会改变结果，须另开一轮。
