21课词表、当课用法、派生索引、预算、折叠答案及重复长阅读行检查通过；263组都能定位首次教学与日文练习。前3天练的是词内辨形和标签，不算完整句子运用。逐项自审和剩余负担风险见[REVIEW](../../02-course-design/REVIEW.md)。

## 新文本诊断

先冻结27份课程/选词/索引文件，后检索新来源。选取首个完整说明小节或首段，不按已知词多少挑句：

| 来源与具体范围 | 单位数 | v3支持判断 | v4支持判断 |
| --- | ---: | ---: | ---: |
| [横滨市易读图书馆指南](https://www.city.yokohama.lg.jp/lang/residents/ej/life/libinfo-ej.html)：首个登记小节，483字符 | 16 | 50.0% | 46.9% |
| [新宿区生活规则](https://www.city.shinjuku.lg.jp/tabunka/wakamatsu01_000001_00061.html)：首个垃圾投放规则表，200字符 | 8 | 18.8% | 18.8% |
| [新美南吉《飴だま》](https://www.aozora.gr.jp/cards/000121/files/4723_13209.html)：首段，43字符 | 4 | 37.5% | 25.0% |

“支持判断”是编者在假设记住所教内容时，逐项判断课程能否支持读出信息；完整1分、部分0.5分、核心信息缺乏支持0分。**不是模型忘掉日语后的真实答卷，也不是真人理解率。** 同一段用同一标准检查v3与v4；不利用模型原有日语知识把未教的词也算已懂。源码恢复原文后可以重新审查每一项判断，但计分程序只验证既有判断和算术。

v4共28个信息单位：完整支持1、部分支持18、缺乏支持9；折半计分10/28＝35.7%。v3是11/28＝39.3%。样本很少，且两篇是行政实用文本、童话只取首段；**不能把这个合并数推广为学生对一般日语的理解比例，也不能与第6轮约70%直接比较**。

具体缺口：可读出借书免费、部分人物资格、上午八点截止、不要做某事等关系；卡证与申请材料、垃圾分类动作、春天/旅客/渡船等内容仍缺。已记录在[support-units.tsv](support-units.tsv)。本轮没有据此再加词或改评分，让当前版本保持可评价。

未重新做新的番剧或漫画整句测试：这两类本轮只有曝光样本的词形回归。也没有独立评分员、真人计时或遗忘测量。当前证据支持“课稿完整且减负”，不支持“阅读效果已提升”。

## 可复算与恢复

```sh
python3 learning-materials/tools/workspace.py check
python3 learning-materials/tools/workspace.py regression --current
python3 learning-materials/04-evaluation/round-07/check.py --check
python3 learning-materials/tools/test_portability.py
```

首次需按[START-HERE](../../START-HERE.md)完成setup。第7轮支持分数的复算本身只用Python标准库，无需重新下载外部原文。查看/复核原文时执行：

```sh
python3 learning-materials/04-evaluation/round-07/check.py --fetch-originals --check
```

下载到忽略的`.cache/round-07`，校验原始字节和选段哈希，不发布第三方整段原文。网站更新导致哈希变化会拒绝，不能保证未来随时可重下载同一版本，需要可信旧副本。当前三份缓存原件与选段均已校验。

`before/manifest.json`保存改课前26份文件；只用于历史比较和独立目录恢复，不是第二套当前正文。跨设备测试改为显式读取该冻结快照，5项检查通过：历史全部样本重放、篡改统计拒绝、改课不能冒充旧版、词形越界要求原文、错误下载不覆盖文件。

`freeze.json`保护本次课文；`evidence-manifest.json`保护协议、样本、逐项判断和回归结果。`check.py`校验后生成/比较`support-results.json`，不会自动重判学生理解。后续改课需新一轮冻结，本轮新文本已经曝光，转回归使用。

没有接入网站、修改部署或凭据、提交或推送；既有应用修改保持原样。
