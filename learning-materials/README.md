# Happy-Japanese 教材与课程准备

**换设备继续：[安装、校验、重跑与优化入口](START-HERE.md)。** 公开仓库包含课程与评估资料；完整第三方教材由脚本下载到本地并校验，词形回归不依赖旧电脑临时文件。

教材内容、21天课程、独立测试集分开维护。当前v3已把777组番剧／漫画优先词实际编进课文，并补全关键表达。换8部新作品的16段检查后，同一批原文上的正式词表匹配率由28.2%升至48.1%；仍未证明21天读懂90%，真实初学者计时与学习效果尚未测量。
